# Robot-Configurator-and-Compatability-checker
## Project Overview 
The Robo Configurator & Compatibility Checker is a web application that helps users select robot components and check their compatibility. It identifies possible issues, explains errors, and calculates the estimated total cost. The project aims to make robot design easier for beginners while helping us learn software development, electronics, and robotics.
